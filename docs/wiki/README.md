# Wiki source

These files are the source of the [Rony.Net wiki](https://github.com/archofthings/Rony.Net/wiki).
Edit them here, in a pull request. When the change reaches `main`, the
[Publish wiki](../../.github/workflows/wiki.yml) workflow copies them to the wiki.

- File names are page names: `Getting-Started.md` becomes the "Getting Started" page.
- Link between pages by page name, for example `[Servers](Servers)`.
- `_Sidebar.md` and `_Footer.md` appear on every page.
- Every code example is a test in [`samples/Rony.Samples`](../../samples/Rony.Samples). Update the sample too when you change an example.
