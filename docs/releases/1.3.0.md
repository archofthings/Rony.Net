# Rony.Net 1.3.0

Match requests by their JSON content, answer with the capture groups of a regular expression, and turn a conversation with a real server into a mock: record it once through a proxy, then replay it in your tests.

**No breaking changes:** code written for 1.0, 1.1 or 1.2 compiles and behaves the same.

```console
dotnet add package Rony.Net --version 1.3.0
```

## ✨ What's new

### JSON requests
```csharp
server.Mock.SendJson(j => j["type"].AsString() == "login").Receive("{\"ok\":true}");
server.Mock.SendJson(j => j["user"]["roles"][0].AsString() == "admin").Receive("{\"admin\":true}");
```
`j` is a `JsonData`: a small read-only JSON value parsed by Rony.Net itself, so the core package still has no dependencies. Missing properties and indexes give an "undefined" value instead of throwing, and a request that is not JSON simply does not match. `JsonData.Parse(...)` is also available inside your own `Receive(...)` functions.

### Capture groups in the response
```csharp
server.Mock.Send(new Regex(@"^HELLO (\w+)$")).ReceiveMatch(m => $"HI {m.Groups[1].Value}");
server.Mock.Send(new Regex(@"^GET (\d+)$")).ReceiveMatch(m => $"ITEM {m.Groups[1].Value}").ThenMatch(m => "GONE");
```
These are new methods rather than `Receive(...)` overloads, so existing calls such as `Receive(x => "pong")` stay unambiguous.

### Record and replay
```csharp
// Once: record the real server
using var proxy = new RecordingProxy("real.host", 5000) { Framing = MessageFraming.Delimiter("\n") };
proxy.Start();
// ... point your client at proxy.Port and run it ...
await proxy.WaitForConnectionsClosedAsync();
proxy.Recording.Save("login.rony.json");

// In tests: answer like the real server did
using var server = new MockServer(new TcpServer(0) { Framing = MessageFraming.Delimiter("\n") });
server.Replay(Recording.Load("login.rony.json"));
server.Start();
```
- `RecordingProxy` relays TCP, or TLS on either side (`Certificate`, `TargetTls`), and only watches: bytes are forwarded unchanged and at once. It records every message per direction, split by your framing.
- The recording is plain JSON (text, or base64 for binary data) that you can read and edit by hand.
- `Replay` turns it into ordinary rules: the greeting becomes `OnConnect()`, each request its reply, a repeated request a sequence, plus silence, disconnects and replies made of several messages.
- UDP is not supported, and recorded delays are not replayed.

## 🧹 Repository
- Shared package metadata in one `src/Directory.Build.props`. The packages' contents are unchanged.
- An `.editorconfig`, with a formatting check in CI.
- GitHub actions updated to `checkout` and `setup-dotnet` v5.
- The old tests no longer use fixed ports or fixed waits, so back-to-back test runs work on macOS.

## 📦 Packages
`Rony.Net`, `Rony.Net.Xunit`, `Rony.Net.Xunit.v3`, `Rony.Net.NUnit` and `Rony.Net.MSTest`, all at 1.3.0. The test framework packages have no changes of their own.
